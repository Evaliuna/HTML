9. The Invisible Work (Head & Meta)

<meta>, <link>, <base>, <noscript>

Not everything in HTML is visible. Inside the <head> you have:

  • <meta charset="UTF-8">: Defines the character encoding.
  • <meta name="description" content="...">: Tells Google what your page is about.
  • <meta name="viewport" content="...">: Ensures the site looks good on mobile.
  • <noscript>: Shows a message if the user has disabled JavaScript.

13. Master List of Global Attributes

These attributes can be applied to ANY HTML tag:

Attribute Purpose
id Unique identifier for CSS/JS
class Classification for groups of elements
style Inline CSS (Last resort)
title Tooltip text when hovering
tabindex Controls focus order for keyboard users
draggable="true" Allows users to drag the element
spellcheck="true" Checks spelling in editable areas
lang="en" Specifies the language of the element content
